# Project Statement

## Problem Statement

Managing student records manually can be difficult when the number of students increases. 
The Student Management System provides a simple command-line application to add, view, 
search, update, delete, sort, and manage student records efficiently.

## Scope of the Project

The project focuses on managing basic student information such as student ID, name, 
age, course, email, and marks.

The system provides:
- Student record management
- Searching student records
- Updating and deleting records
- Grade calculation
- Sorting student records
- Input validation
- File-based data storage

The project is designed as a command-line Java application and does not require a 
graphical user interface or external database.

## Target Users

The target users of this project are:

- Students learning Java programming
- Teachers or faculty managing basic student records
- Small educational environments requiring a simple student record system

## High-Level Features

1. Add Student
2. View All Students
3. Search Student
4. Update Student
5. Delete Student
6. Calculate Student Grade
7. Sort Students
8. Save Student Data
9. Load Student Data
10. Input Validation
